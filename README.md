# Blackjack（21 點）

單人、無後端的網頁版 Blackjack。使用一副 52 張牌跨局遊玩，初始籌碼 1,000。牌堆在一局結束後若少於 13 張，下一局前會顯示洗牌訊息並等待 5 秒。遊戲沒有算牌提示或隱藏的勝率調整。

## 玩法與操作

1. 按「開始挑戰」，用 `+10`、`+25`、`+50`、`+100` 累加下注，或按 `All In`。按「清除」可重設尚未確認的下注。
2. 按「開始遊戲」確認下注並發牌。玩家兩張明牌；莊家一張明牌、一張暗牌。
3. 用 **Hit** 補牌、**Stand** 停牌、**Double** 加倍後只補一張牌，或在起手兩張 Blackjack 點數相同且籌碼足夠時用 **Split** 分牌。Double 和 Split 都需要再投入等額籌碼。
4. 分牌後先操作左手，再操作右手。A+A 分牌時兩手各補一張後自動停牌。每手獨立與莊家比較；一局分牌仍只算一個完成局數。
5. 結算後可開始下一局或離開牌桌。籌碼歸零會自動結束挑戰。結束畫面顯示成績；首頁保存最長存活局數與單次最多 Blackjack 次數。

## 規則摘要

- A 可算 1 或 11；J、Q、K 算 10。超過 21 點立即爆牌。
- 只有起手兩張直接湊成 21 才是 Blackjack。玩家和莊家同時 Blackjack 為平手；玩家單獨 Blackjack 獲利 3:2，小數獎金向上取整。分牌後的 21 只算普通 21。
- 莊家低於 17 點必須補牌，17 點或以上停牌，包含 Soft 17。
- 普通勝利獲利 1:1；平手退回本金；失敗失去下注。

## 檔案

- `index.html`：頁面結構
- `style.css`：桌面、撲克牌與響應式樣式
- `deck.js`：52 張牌、點數、洗牌與依序抽牌
- `game.js`：規則、籌碼、回合狀態與統計
- `ui.js`：畫面更新與按鈕事件
- `storage.js`：localStorage 歷史紀錄
- `game.test.js`：規則與結算測試
- `server.js`：開發時可選用的本機服務，遊玩不需要

## 本機開啟

在檔案總管打開專案資料夾，**直接雙擊 `index.html`** 即可遊玩。遊戲只使用本機 HTML、CSS 和 JavaScript，不需要安裝 Node.js、套件或啟動服務。

若要執行開發測試，才需要安裝 Node.js；在專案資料夾執行：

```sh
node --test
```

開發時也可選擇執行 `node server.js`，再瀏覽 `http://localhost:8000`。這不是玩家開啟遊戲的必要步驟。
